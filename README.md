## 📦 Skills

### job-seeker

**功能**: 帮助求职者搜索招聘平台、分析公司口碑、推荐合适岗位的AI助手

**安装**: 直接对我说"帮我安装 job-seeker skill（https://github.com/cszr-liuxiaobo/clawskills-all-in-one/tree/main/skills/job-seeker）"，我会自动阅读SKILL.md并完成安装。

或手动安装：在 `openclaw.json` 的 `skills.entries` 中添加 `"job-seeker": { "enabled": true }`，然后重启OpenClaw。

**详细说明**: [SKILL.md](./skills/job-seeker/SKILL.md)
