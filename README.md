# 🦞 求职智能体「职场顾问」使用指南

## 简介

「职场顾问」是一个专门帮助求职者找工作的AI助手，帮你：
- 🔍 搜索各大招聘平台职位
- 📊 分析公司背景和口碑
- 🎯 根据你的需求推荐合适的岗位

---

## 开始使用

### 基础对话

直接发消息给我，告诉我你的情况：

```
你好，我想找工作
```

或者直接描述你的需求：

```
帮我看看阿里在上海的算法岗位
```

---

## 首次使用 - 信息收集

第一次使用时，我会问你几个问题来了解你的情况：

| 问题 | 说明 |
|------|------|
| 校招还是社招？ | 决定搜索哪些平台 |
| 什么学历和专业？ | 匹配岗位要求 |
| 想去哪个城市？ | 地域筛选 |
| 想做什么岗位？ | 岗位方向 |

---

## 查看岗位详情

告诉我你对哪个岗位感兴趣，我会帮你深度分析：

**分析内容包括：**
- 岗位匹配度（JD要求 vs 你的技能）
- 薪资竞争力
- 公司背景和口碑
- 潜在风险提示

---

## 反馈优化

每次推荐后，请告诉我你的想法：

| 你的反馈 | 智能体动作 |
|---------|-----------|
| "太累了" | 加重work-life-balance分析 |
| "钱太少" | 关注薪资竞争力 |
| "想稳定" | 推荐国企/事业编 |
| "想成长" | 推荐大厂/核心业务 |

---

## 支持的搜索范围

### 招聘平台
- Boss直聘、牛客网、拉勾网（互联网）
- 智联招聘、前程无忧（传统企业）
- 猎聘（高端岗位）
- 国聘网（央企国企）

### 官方渠道
- 高校就业网（校招）
- 政府人才引进（事业编）
- 公司官网招聘

### 口碑探查
- 小红书（员工体验）
- 脉脉（职场评价）
- 知乎（公司分析）

---

## 限制说明

- ⚠️ 不代投简历，只提供信息
- ⚠️ 薪资数据来自网络，仅供参考
- ⚠️ 决策需谨慎，建议多方验证
